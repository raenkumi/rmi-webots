## Assignment Challenges

Develop an agent suitable to control the movement of a robot on different scenarios.

### Challenge 1

Navigate an unknown closed path as fast as possible.

### Challenge 2 - Mapping

Explore an unknown maze in order to extract its map.

### Challenge 3 - Planning

Explore an unknown maze, extract its map with target spot locations, then compute the shortest closed path that visits those spots.
